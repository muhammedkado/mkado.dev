By Muhammed Kado · İstanbul

Computer engineer in İstanbul, working full-stack. Since 2023 I build REST APIs and web interfaces in PHP, Laravel and Zend Framework at USTEK RFID, shipping a laundry-management platform used by commercial laundries, hotels and hospitals. On my own time I build with React and Next.js. The seven applications below are deployed and yours to try.

USTEK builds RFID-based laundry management for commercial laundries, hotels and healthcare, deployed in more than 30 countries. I work on the web platform that sits on top of the readers and terminals. Built and extended REST APIs and web interfaces in PHP, Laravel and Zend Framework 1 for real-time RFID inventory tracking, automated billing and logistics.

Worked with the hardware team to keep data flowing reliably between UHF RFID terminals, readers and the platform. Refactored error-prone modules, cutting production incidents for clients around the world.

How this paper is printed

Everything on this site runs on one Always-Free Oracle Cloud VM behind Cloudflare, deploys with a single command over SSH, and resets itself every night.

Hosting
One Always-Free Oracle Cloud VM, nginx and php-fpm, behind Cloudflare
Deploy
One command over SSH. The server never talks to GitHub: no token, no deploy key
Reset
Demo data is re-seeded nightly, so every visitor gets a clean account
Health
Every five minutes a probe checks each app and writes a small JSON file; the status dots read it
Mail
Contact form stores first, then notifies; Turnstile keeps the bots out
