Method

Seven applications on one free virtual machine

Everything on this site runs on one Always-Free Oracle Cloud VM behind Cloudflare, deploys with a single command over SSH, and resets itself every night.

Hosting
One Always-Free Oracle Cloud VM, nginx and php-fpm, behind Cloudflare
Deploy
One command over SSH. The server never talks to GitHub: no token, no deploy key
Reset
Demo data is re-seeded nightly, so every visitor gets a clean account
Health
Every five minutes a probe checks each app and writes a small JSON file; the status dots read it
Mail
Contact form stores first, then notifies; Turnstile keeps the bots out
